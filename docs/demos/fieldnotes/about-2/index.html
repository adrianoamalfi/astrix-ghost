About

Field Notes is one person thinking out loud about creative work. I make small things — some software, some writing, some things that never ship — and I write down what I learn while it is still fresh enough to be useful.

No hustle, no ten-step frameworks. Just honest notes from inside the work, published in public so that future-me, and maybe you, can find them again.
